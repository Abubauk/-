# Расчёт окон — Telegram Mini App

Вводите ширину и высоту окна, число секций и открывающихся створок — приложение считает, сколько штук и метров каждой детали нужно. Результаты можно сохранять и смотреть в истории.

## Запуск

Нужен Node.js 18 или новее. Установка пакетов не требуется.

```
BOT_TOKEN=123456:ABC... PORT=3000 node server.js
```

Без `BOT_TOKEN` сервер работает в режиме разработки (без проверки Telegram) — удобно проверять в обычном браузере на http://localhost:3000.

Результаты хранятся в `data/results.json`.

## Подключение к Telegram

1. Создайте бота у @BotFather (`/newbot`) и возьмите токен.
2. Разместите сервер на любом хостинге с **HTTPS** (Telegram открывает только https-адреса). Подойдёт VPS, Render, Railway, Fly.io и т. п. Обязательно задайте переменную `BOT_TOKEN`.
3. В @BotFather: `/newapp` (или `/mybots` → ваш бот → Bot Settings → Menu Button) и укажите адрес вашего сервиса.
4. Откройте бота в Telegram и нажмите кнопку меню — приложение запустится.

С `BOT_TOKEN` у каждого пользователя своя история: личность проверяется по подписи Telegram.

## Как менять детали и формулы

Все детали лежат в `parts.json`. Для каждой детали:

- `name` — название;
- `unit` — `м`, `м²` или `шт`;
- `pcs` — формула количества нарезанных штук;
- `qty` — формула общей длины (м) или площади (м²); для `шт` не нужна.

Доступные переменные в формулах (размеры в метрах):

| Переменная | Что это |
|---|---|
| `w`, `h` | ширина и высота окна |
| `n` | число секций |
| `s` | число открывающихся створок |
| `sw`, `sh` | размеры створки (секция минус 4 см) |
| `gw`, `gh` | размеры стеклопакета секции (минус 12 см) |
| `P` | периметр окна |

Добавить деталь — добавьте строку в `parts.json` и перезапустите сервер.

> Формулы в `parts.json` — типовые значения для ПВХ-окна. Подставьте размеры вашего профиля (ширина рамы, импоста, зазоры), чтобы расчёт совпадал с вашим производством.
